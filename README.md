# MatchNeRF Project Page

This branch holds the static project page for **Explicit Correspondence Matching for Generalizable Neural Radiance Fields** (TPAMI 2025).

The page is published by GitHub Pages from this `gh-pages` branch and lives at <https://donydchen.github.io/matchnerf/>.

Paper: <https://arxiv.org/abs/2304.12294v2>

The research code lives on the `main` branch of this same repository.

## Notes

This is a plain HTML/CSS/JS site. The empty `.nojekyll` file at the root tells GitHub Pages to skip Jekyll processing and serve the files exactly as they are.

The page itself was vibe-coded with [AnyCoder](https://huggingface.co/spaces/akhaliq/anycoder) and [ChatGPT](https://chatgpt.com/).

For feedback or questions, contact [Donny](http://donydchen.github.io/).
